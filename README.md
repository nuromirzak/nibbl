## Install

In Claude Code:

```
/plugin marketplace add https://getnibbl.pages.dev/marketplace.json
/plugin install nibbl@nibbl
```

No account, no login, no API key. An egg appears above your prompt. Keep working and it hatches.

## Why you will like it

- **It is yours.** Every nibbl is one of a kind, with its own genome and a serial number. Nobody else will ever have the same one.
- **It notices your work.** A failing tool drops a bug into its tiny world. Green tests? It eats the bug. The rest you will discover yourself.
- **It grows with you.** From egg to baby to forms you only see by getting there. How you work decides what it becomes.
- **It never gets in the way.** It never blocks Claude, never nags and never dies. Leave for a month and it is still there, asleep.
- **It costs nothing.** Zero model tokens, nothing to buy, nothing to farm.

## FAQ

**Does it slow Claude down or cost tokens?** No. It is drawn by plain code and never calls the model.

**What does it send?** Only that something happened (a turn, a passing check, a commit) and when. Never your code, prompts, files or commands. Details in [how it works](docs/how-it-works.md).

**Can it die?** Never.

**Can I reroll?** No. That is what makes it yours.

**Is it open source?** Yes, MIT. See [how it works](docs/how-it-works.md) if you want to look inside or help.
