# mod-spike

Throwaway spike, not the product: a local-only Claude Code mod (function-hooks plugin, Claude Code 2.1.287) that draws a real nibbl from `@nibbl/core` above the prompt, so we could check the risky rendering assumptions (Raster with a transparent background, clicking the pet, short bands) before building the real mod. There is no server: the hatch roll uses `Math.random` mixed with the clock, XP is scored locally with `scoreEvents`, and everything lives in the mod's `$.store`. Build with `pnpm --filter @nibbl/mod-spike build` (bundles `src/` plus core into the session's dev-mods `nibbl/` folder, override with `NIBBL_MOD_DIR`), type-check with `pnpm --filter @nibbl/mod-spike typecheck`, then run `claude plugin validate` and `claude plugin test` on the built folder. Delete this app once the real mod exists.
